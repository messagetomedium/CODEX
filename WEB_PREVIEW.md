# Как смотреть текущий этап игры

Постоянный адрес: **https://messagetomedium.github.io/CODEX/**.

После каждого согласованного этапа Codex:

1. Проверяет проект, тесты и Godot Web export.
2. Отправляет готовые изменения в main, сохраняя рабочую ветку и коммиты.
3. Дожидается успешной сборки и публикации GitHub Actions.
4. Проверяет сайт и присылает эту же ссылку с коротким описанием изменений.
5. Ждёт отзывов и подтверждения перед следующей игровой задачей.

Открывайте ссылку и проверяйте текущий этап. Если браузер показывает старую
версию, обновите страницу с очисткой кеша (Ctrl+Shift+R / Cmd+Shift+R).
Изменения публикуются после завершения Actions; при неудачной новой сборке
на сайте остаётся предыдущая успешно опубликованная версия.

Текущий этап — Task 4: работает полный раунд (3 гола за 6 попыток).
Счётчик попыток увеличивается при первом движении нового мяча. Слабый недолёт
позволяет продолжить ту же попытку. После каждого исхода — короткое сообщение
примерно на 2,5 секунды, затем следующий мяч автоматически.

Как проверить:

1. Откройте ссылку, выберите «Забить гол», нажмите «Начать» и разрешите микрофон.
2. Говорите тихо — мяч катится; замолчите — остановится. Резкий громкий звук
   вызывает удар. Настройки микрофона и задержка шкалы сохранены.
3. Попадание в раму, сейв, ловля с поднятыми руками и перехват имеют разные
   подписи. При голе меняется счёт, реагирует сетка и появляется короткий совет.
4. После трёх голов или завершения шестой попытки появится **большое окно по
   центру, как инструкция**. «Повторить» сразу начнёт новый раунд без правил.
   «Главное меню» вернёт к карточкам; «Следующий уровень» пока отключён.

«Сброс» доступен всегда и закрывает микрофон. Молчание не завершает попытку
и не возвращает в меню. Игра не воспроизводит звуков и не записывает речь.
Большое окно появляется только в конце всего раунда, после отдельного мяча
сообщение остаётся компактным — это отдельно подтверждено владельцем.

Автоматические браузерные проверки используют искусственный вход; ощущения
от настоящего голоса проверяет владелец по опубликованной ссылке.

Однократная настройка репозитория: Settings → Pages → Source: GitHub Actions.
Точный статус публикации виден в Actions → Build Godot Web and publish Pages.
