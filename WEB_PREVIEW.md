# Как смотреть текущий этап игры

Постоянный адрес: **https://messagetomedium.github.io/CODEX/**.

После каждого согласованного этапа Codex:

1. Проверяет проект, тесты и Godot Web export.
2. Отправляет готовые изменения в main, сохраняя рабочую ветку и коммиты.
3. Дожидается успешной сборки и публикации GitHub Actions.
4. Проверяет сайт и присылает эту же ссылку с коротким описанием изменений.
5. Ждёт отзывов и подтверждения перед следующей игровой задачей.

Открывайте ссылку и проверяйте текущий этап. Если браузер показывает старую
версию, обновите страницу с очисткой кеша (Ctrl+Shift+R / Cmd+Shift+R).
Изменения публикуются после завершения Actions; при неудачной новой сборке
на сайте остаётся предыдущая успешно опубликованная версия.

Текущая версия — три раунда с усложнением. В каждом нужно забить 3 гола за
6 попыток. Ворота стали крупнее, касания краем мяча прощаются, защитники
появляются только перед воротами.

Как играть:

1. Откройте ссылку, выберите «Забить гол», нажмите «Начать» и разрешите микрофон.
2. На шкале отмечено «Тихо: катить» и «Резко: удар». Держите голос в тихом
   диапазоне для движения. Замолчите — остановка; резко добавьте громкость
   выше риски удара — подброс. Долгий громкий звук не даёт серию ударов.
3. В первом раунде один медленный защитник. Во втором до двух, в третьем до
   трёх, они могут идти навстречу друг другу на разных дорожках. Вратарь
   ускоряется постепенно, со второго раунда делает повторяемые паузы и развороты.
4. После победы в первом/втором раунде нажмите «Следующий раунд».
   При неудаче «Повторить» начинает текущий раунд, прошлые победы сохраняются.
5. После третьей победы появится большое окно завершения игры с суммой голов
   и попыток в пройденных раундах. «Сыграть сначала» вернёт к первому раунду.

После отдельного мяча — короткое сообщение и автоматический следующий мяч.
Слабый недолёт продолжает ту же попытку. Большие итоги расположены по центру,
как инструкция; правила при переходах и повторах не показываются снова.
«Сброс» всегда возвращает в меню и закрывает микрофон. Молчание не завершает
попытку и не вызывает сброс. Игра не записывает речь и не воспроизводит звуков.

Пороги и задержки микрофона сохранены. Автоматические браузерные проверки
используют искусственный вход; ощущения от своего голоса проверяет владелец.
Файлы, команды, результаты и реальные снимки — в
[TEST_REPORT_THREE_ROUNDS.md](TEST_REPORT_THREE_ROUNDS.md).

Однократная настройка репозитория: Settings → Pages → Source: GitHub Actions.
Точный статус публикации виден в Actions → Build Godot Web and publish Pages.
