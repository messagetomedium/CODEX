# Task 4 — полный раунд и уточнения владельца

Godot **4.5.2.stable.official.6ce3de25a**, GDScript, Compatibility, Web без потоков.
Постоянный адрес: https://messagetomedium.github.io/CODEX/.

Владелец подтвердил работу Task 3 и разрешил следующий этап, отдельно уточнив:
большое окно нужно только в конце всего раунда, по центру, размером как
инструкция. Контакт с рамой имеет собственное сообщение. Над головой под
перекладиной вратарь поднимает руки и ловит мяч. Уточнения записаны в
`CHANGELOG.md`, соответствующие абзацы GDD/TECH и каталог UI синхронизированы.

## Что работает

- Счёт: первый сдвиг нового мяча расходует одну попытку; остановки, недолёт и
  последующие удары по этому мячу её не увеличивают. Цель 3, лимит 6, раунд 1.
- Короткое событие на 2,5 секунды останавливает механику/голос; затем новый мяч
  автоматически. Гол меняет счёт, деформирует только сетку, показывает совет и
  кодовое украшение. Камера и рама не двигаются. Неудачи — компактные сообщения.
- Текст не перекрывает текущие ворота, игроков, мяч, HUD и Reset: проверяются
  кандидаты из layout, отступы, уменьшение и свободные места. Центр намеренно
  занят только инструкцией и итоговым окном.
- Контакт круга мяча с видимой перекладиной/штангой на линии ворот — `frame`.
  Он проверяется до вратаря и не подписывается как сейв. Защитник сохраняет
  приоритет при одновременном перехвате.
- Мяч над головой под рамой при перекрытии X вратаря — `caught`. Обе руки
  быстро поднимаются к мячу (110 мс, отдельный профиль), мяч фиксируется между
  перчатками. Прыжков и движения вратаря по Y нет. Обычный сейв — `saved`.
- Близкая высокая траектория ограничена рамой на линии ворот, чтобы сохранить
  согласованное отсутствие случайных перелётов: видимый удар в раму возможен.
- Третий гол завершает раунд; шестой мяч доигрывается до исхода. После короткой
  реакции открывается центральный итог по размеру инструкции с фразой из пула
  3/2/1/0, статистикой, «Повторить», «Главное меню» и disabled «Следующий уровень».
- Повтор сбрасывает счёт в том же уровне без инструкции; рабочий микрофон
  переиспользуется. При потере устройства повтор запрашивает его синхронно
  из кнопки. Ошибка микрофона во время события сохраняет состояние и остаток
  его времени. Итог при потере устройства остаётся доступным.
- Общий popup поддерживает промежуточную статистику, но в обычном единственном
  раунде этот вариант не вызывается.

Настройки микрофона/детектора/шкалы, исходный референс, Web export preset и
существующий `.github/workflows/web-pages.yml` сохранены. Task 5 не выполнялась.

## Изменённые файлы

- `scripts/goal/logic/round_progress.gd`: чистый счёт и завершение раунда.
- `scripts/goal/logic/field_projection.gd`, `goal_simulation.gd`, `ball_motion.gd`:
  геометрия рамы, классификация ловли, ограничение близкой дуги.
- `scripts/goal/goal_level.gd`: события, следующий мяч, финал, повтор, паузы.
- `scripts/goal/goal_world.gd`, `world_entity.gd`, `blockout_shapes.gd`:
  деформация сетки и руки, защищённые прямоугольники объектов.
- `scripts/ui/game_notification.gd`, `ui_positioner.gd`, `celebration_burst.gd`:
  компактные события с безопасным размещением и кодовым украшением.
- `scripts/ui/game_info_popup.gd`, `ui_factory.gd`, `ui_animation_controller.gd`:
  слоты статистики/действий, отключённая кнопка, независимые профили.
- `data/config/gameplay.json`, `ui_layout.json`, `ui.ru.json`, `ui_animations.json`:
  параметры геометрии/реакции рук, размер итога, тексты рамы/ловли. Прежняя
  подсказка о ручном сбросе после каждого мяча удалена как устаревшая.
- `tests/round_progress_test.gd`, `task_4_smoke_test.gd`: новые проверки правил,
  событий, всех итогов, retry, ошибок микрофона и пауз.
- `tests/goal_simulation_test.gd`, `task_2_smoke_test.gd`, `task_3_smoke_test.gd`:
  регрессии обновлены для настоящего счёта и нового правила рамы.
- `tests/web_smoke_test.py`, `visual_review.gd`, `visual_review.py`: полный
  браузерный раунд и отдельные контролируемые визуальные проверки.
- `tools/check_tasks_0_1.sh`: новые headless-проверки в существующей цепочке CI.
- Godot `.uid` новых скриптов; `CHANGELOG.md`, GDD/TECH/UI, `WEB_PREVIEW.md`,
  `web/README.md`, этот отчёт, снимки `docs/review/task-4/*.png`.

В нормальном браузерном запуске проверены настоящий Web Audio API с синтетическим
MediaStream, RMS → шкала, ошибки denied/not-found/busy → retry, позднее разрешение
после Reset, освобождение треков, отсутствие мониторинга/передачи голоса,
строгий debug opt-in, катание/масштаб/остановка/дуга. Затем шесть настоящих
клавиатурных debug-импульсов доиграли шесть неудач; проверены компактные события,
большой центральный финал после шестой попытки, disabled Next, повтор без правил.
Рама также видна в этом обычном прохождении. Проверены форматы 16:9 и 4:3.

В отдельном браузерном fixture локальный HTML выбирает `--script` тестового
SceneTree; вход и положение вратаря контролируются. Та же чистая механика
создаёт ловлю и голы, тот же уровень рисует руки/сообщения/итог победы. Проверены
поднятые перчатки с обеих сторон мяча по пикселям и отсутствие ошибок консоли.
Файл HTML в проекте и обычный запуск на Pages этот fixture не выбирают.

Физический микрофон на этом этапе в облаке не проверялся. Его работу и Task 3
ранее подтвердил владелец; новые ощущения от полного раунда/баланса требуют
просмотра владельца. Другие браузеры и мобильные устройства не проверены.
