# «Трибуны»: упрощение интерфейса по правкам владельца

Следующая итерация с 30-секундными раундами и раздельными стартовыми окнами —
[TEST_REPORT_SHORT_ROUNDS.md](TEST_REPORT_SHORT_ROUNDS.md).

Godot **4.5.2.stable.official.6ce3de25a**, GDScript, Compatibility,
однопоточная Web-сборка. Постоянный адрес:
https://messagetomedium.github.io/CODEX/.

## Что изменено

- Единственная шкала поддержки выровнена по горизонтальному центру снизу.
  Узкий белый сегмент без подписей соответствует зоне ничьей `49.5..50.5`:
  его границы читаются из того же конфига, что и условие результата.
- Убраны шкала голоса, заголовок шкалы, проценты преимущества, жёлтая метка
  55, подписи под шкалой, отсчёт до переключения и количество ходов.
- Количество акцентов не показывается во время игры и в окнах победы,
  поражения, ничьей и общего финала. Их влияние на поддержку сохранено.
- В момент завершения шкала догоняет точный итоговый счёт, даже когда
  активного хода уже нет. В ходе игры сохранено плавное движение через Tween.
- Профили сложности, формула поддержки, микрофон, звук соперника и переходы
  между тремя уровнями сохранены. Первая мини-игра и workflow не изменены.

## Изменённые файлы

`scripts/stands/ui/stands_hud.gd`, `tug_bar.gd` — состав HUD и белая зона.
`scripts/stands/stands_level.gd` — одно поле статистики результатов вместо
двух, удаление обращения к голосовой полосе при ошибке микрофона.
`data/config/stands_layout.json`, `stands_gameplay.json`, `ui.ru.json` —
центрирование и удаление устаревших полей/текстов. Обновлены GDD, сценарий UI,
архитектура, описание механики, инструкция просмотра и changelog.
Локальная fixture `tests/stands_visual_review.gd` приведена к новому API HUD.
