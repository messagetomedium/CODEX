# Перехват с учётом глубины поля

Godot **4.5.2.stable.official.6ce3de25a**, GDScript, Compatibility,
однопоточный Web. Постоянный адрес: https://messagetomedium.github.io/CODEX/.

## Что изменено

По замечанию владельца заменено первоначальное правило перехвата только по
силуэтам. Мяч уже имел логическую глубину `progress`; теперь защитники имеют
`depth` в той же системе координат. Сцена остаётся 2.5D: для неподвижной камеры
и плоских спрайтов переход на 3D не нужен, чтобы правильно разделять глубину.

- Дорожка переводится в глубину по точке контакта мяча с землёй. Центр
  летящего мяча для этого не используется. Ноги защитника и порядок
  перекрытия рисуются через ту же проекцию.
- Контакт возможен только при одновременном пересечении глубины и уменьшенных
  экранных контактных областей. Дальний мяч не блокируется ближним игроком,
  ближний — дальним. Прямой контакт на одной глубине перехватывается.
- Проверяется весь отрезок движения между кадрами: пересекаются интервалы
  времени, когда совпадают глубина и контактные области. Это исключает
  проскок при быстром ударе и ложный контакт, когда X и глубина совпадали
  в разные моменты.
- Половина толщины контакта по глубине: мяч `0.012`, защитник `0.025`
  в единицах `progress` (весь путь от старта до ворот — 1). Эти параметры
  находятся в JSON и допускают дальнейшую балансировку.
- Мягкие касания, три раунда, 3 гола/6 попыток, микрофон и размеры ворот
  сохранены. Мяч выше всей контактной области защитника может пройти над ним.
  Вратарь и рама по-прежнему проверяются на линии ворот.

## Изменённые файлы

- `scripts/goal/logic/field_projection.gd`: проекция наземной точки и обратное
  преобразование дорожки в глубину.
- `scripts/goal/logic/screen_collision.gd`: временной интервал контакта
  по глубине, ограничение swept-контакта этим интервалом.
- `scripts/goal/logic/goal_simulation.gd`: координата глубины каждого
  защитника и совместная проверка контакта.
- `scripts/goal/goal_world.gd`: ноги защитника и порядок перекрытия
  используют наземную проекцию глубины.
- `data/config/gameplay.json`: две толщины контакта по глубине.
- `tests/depth_collision_test.gd` / `.uid`: регрессии глубины;
  `tests/goal_simulation_test.gd`, `campaign_test.gd`: прежние прямые
  контакты перенесены на совпадающую глубину без удаления проверок.
- `tests/visual_review.gd`, `visual_review.py`: разная глубина без перехвата,
  одинаковая с перехватом; проверка перекрытия спрайтов в Web.
- `tools/check_tasks_0_1.sh`, `validate_handoff.py`: включение тестов в
  существующий CI и валидация толщины/разделения дорожек.
- AGENTS/GDD/TECH/CODEX_TASKS/CHANGELOG: прежнее чисто экранное правило
  явно заменено по замечанию владельца; `WEB_PREVIEW.md`, этот отчёт
  и `docs/review/depth/*.png`.

`.github/workflows/web-pages.yml`, экспортные настройки, референс
и тексты интерфейса сохранены.

## Проверки

```sh
GODOT_BIN=/workspace/.tools/godot-4.5.2/godot bash tools/check_tasks_0_1.sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory build/web
python3 tests/web_smoke_test.py --output /workspace/artifacts/matryoshka-depth
python3 tests/visual_review.py --output /workspace/artifacts/matryoshka-depth
```

Godot import, валидация JSON и Web release export прошли. Новые **32/32**
проверки подтверждают разную глубину при действительном наложении картинок,
катание на каждой дорожке всех трёх раундов, высоту отдельно от глубины,
контакт между концами длинного кадра, совместное совпадение во времени,
однократный исход, одинаковую точку остановки при мелких и крупных шагах,
реальный быстрый удар с близкого расстояния.

Регрессии прошли: Task 1/2/3/4 — 48/22/20/111, движение и столкновения — 42,
рама/правила раунда — 64, кампания/сцена — 48/31, детектор — 21+21,
JS-микрофонный мост — 11. Логи: `/tmp/depth-checks.log`, `build/checks/*.log`.

Обычный Chromium запуск также прошёл: игра доведена до настоящего итога
раунда и перехода через доступную кнопку Next/Retry. Проверены катание,
остановка, полёт, синтетический Web Audio/RMS и шкала, отказ/отсутствие/занятость
микрофона и retry, поздний grant после Reset, очистка ресурсов, отсутствие
мониторинга/передачи голоса, закрытый по умолчанию debug и изменение viewport.

Браузерные результаты и реальные снимки сохраняются в
`/workspace/artifacts/matryoshka-depth/`; автоматический микрофонный вход
синтетический. Физический микрофон, другие браузеры и мобильные устройства
на этом этапе не проверялись.

Chromium с контролируемым входом подтвердил оба состояния глубины в настоящем
Web export. Проверена правильная отрисовка ближнего защитника поверх дальнего
мяча без перехвата, а также перехват на совпадающей глубине. Повторно прошли
ловля с поднятием рук, гол, рама, раунды 2/3 и центральные итоги в 16:9/4:3;
ошибок GDScript/JavaScript не обнаружено. Fixture запускается только локальным
`--script` через подмену HTML в тесте, обычный запуск игры не изменён.
