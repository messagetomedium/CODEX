Работай с уже подключённым GitHub-репозиторием «Матрёшка» в облачном Codex.

Сначала изучи AGENTS.md, GDD_Matryoshka_v1.0.md, SCREEN_SCRIPT_UI_v1.0.md,
TECH_ARCHITECTURE_v1.0.md, CODEX_TASKS_v1.0.md, GITHUB_SETUP.md,
data/config/*.json и references/goal_scene_original.png.

ВАЖНО: технологический стек — Godot 4.5.2 standard, GDScript, Godot Web export.
НЕ используй Phaser/Vite/TypeScript. В корне уже есть минимальный Godot-проект
(project.godot, сцена-заглушка, export_presets.cfg) и готовый GitHub Actions
workflow .github/workflows/web-pages.yml. Не создавай новый вложенный проект,
не удаляй экспортные настройки, документацию и исходный референс.

Сделай СТРОГО задачи 0 и 1 из CODEX_TASKS_v1.0.md. Цель этого этапа:
1. Проверить и при необходимости настроить Godot в облачной среде; для
   установки можно использовать bash tools/setup_codex_env.sh. Выполнить
   доступные headless импорт/тест/экспорт и проверку JSON.
2. Заменить стартовую заглушку на настоящее главное меню из трёх карточек:
   область изображения сверху, название игры под ней, мелкая фраза ниже,
   БЕЗ общего заголовка. Клик мышью активен только у «Забить гол»;
   «Трибуны» и «Второй комментатор» не кликабельны.
3. Создать единственную пока игровую сцену GoalLevel с 2.5D blockout-полем
   ПО КОМПОЗИЦИИ оригинального референса: статичный фронтальный вид, крупный
   мяч по центру внизу, ворота прямо впереди, плоские placeholders для
   вратаря/защитника. Пока БЕЗ реальной физики и микрофона.
4. При входе в GoalLevel поле уже видно; поверх него общий сменный
   UI popup инструкции: короткая цель, ровно 3 пункта инфографики в одну
   горизонтальную строку, кнопка «Начать». Это НЕ отдельный экран.
   Для клика «Начать» до задачи 2 допустимо явное сообщение, что микрофон
   будет подключён позднее, но не имитируй рабочее управление.
5. Сделать глобальный «Сброс» из любого состояния в главное меню.
   Интерфейсные строки брать ТОЛЬКО из res://data/config/ui.ru.json;
   все UI-анимации писать кодом через Godot Tween, профили брать из
   res://data/config/ui_animations.json; положения из ui_layout.json.
   НЕ добавлять музыку, звуки, GIF, видео или финальную графику.

После выполнения: проверь headless-импорт и экспорт Web (или покажи точную
причину ограничения среды), приложи краткий перечень изменённых файлов,
покажи как посмотреть готовую сборку на GitHub Pages после merge в main.
По возможности дай изображения меню и стартового попапа, но не выдавай
снимки за реальные, если браузерный запуск не выполнялся. Подготовь PR/коммит,
не переходи к задаче 2 без моего подтверждения.
