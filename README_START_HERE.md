# «Матрёшка» — Godot 4.5.2 / Codex Cloud / GitHub Pages (v1.0)

**Это подготовленный репозиторий для разработки, не готовая игра.** В нём уже находится минимальный **собираемый Godot-проект с заглушкой**, исходный игровой дизайн, редактируемые JSON-файлы, композиционный референс и workflow автоматического экспорта на GitHub Pages.

## Начни с этих трёх действий

1. **Распакуй ZIP и загрузи содержимое в корень GitHub-репозитория**, включая скрытую `.github/` — не загружай ZIP как один файл. `project.godot` должен оказаться в корне. Подробная инструкция: `GITHUB_SETUP.md`.
2. В GitHub один раз включи `Settings → Pages → Build and deployment → Source: GitHub Actions`. В Action после первого коммита появится тестовая Godot-заглушка, когда сборка успешно завершится.
3. В облачном Codex выбери этот репозиторий и вставь `CODEX_FIRST_PROMPT.txt`. Он выполнит **только Tasks 0–1**: меню + blockout сцены + UI-инструкция, без микрофона и без финальной графики.

## Фиксированные требования v1.0

- **Два экранных типа:** главное меню и игровой уровень. Всё остальное (intro, гол, перехват, ошибка mic, intermediate/final) — общий UI overlay поверх уровня.
- **Меню:** только три карточки без общего заголовка. Каждая карточка: иллюстрация / название / краткое действие. «Забить гол» кликается, остальные disabled.
- **Первый прототип:** только «Забить гол», Раунд 1, три гола максимум за шесть попыток; статичная камера, плоские спрайты и псевдоглубина; вратарь X, защитник один за раз, голос катит и запускает мяч по дуге.
- **Всё UI-анимируется кодом Godot** (`Tween`) с настройками из JSON для каждого блока. Позже можно заменить статичные пиктограммы на маленькие программные анимации независимо от контейнера.
- **Тексты:** меняются только в `data/config/ui.ru.json` по ключам, без редактирования GDScript. Случайные советы — короткие тренерские/футбольные, соответствующие реальным механикам.
- **Звук:** никаких воспроизводимых игровых звуков. Mic используется только для анализа. Нет автосброса при молчании, есть глобальная кнопка Reset.
- **Графика:** первый этап blockout без финального арта, композиция строго по исходной иллюстрации. Исторические звуки/видео пока не используем.

## Как редактировать позже

**Тексты:** `data/config/ui.ru.json`; затем `python3 tools/sync_ui_docs.py`, `python3 tools/validate_handoff.py`. При Godot Web конфиги упаковываются в `.pck`, поэтому после изменения GitHub Actions пересоберёт сайт, когда изменения будут в `main`.

**Анимации:** `data/config/ui_animations.json`. Изменять `durationMs`, `delayMs`, `easing`, `opacity`, `yPx`, `scale` нужного именованного блока. Godot Tween-контроллер должен применить только изменения этого блока. **Не создавать отдельные видеоролики/GIF для UI.**

**Игровые настройки:** `data/config/gameplay.json`; кроме утвержденных голы=3 / попытки=6 / раунд=1, числовые параметры — предварительные для настройки после реального игрового теста.

**Дополнительные ассеты:** `assets/backgrounds/`, `assets/sprites/`, `assets/ui/`. Манифест путей — `data/config/asset_manifest.json`. Не рисовать всю игру одним плоским изображением.

## Реальная проверка

CI проверяет Godot импорт и сборку, **но не оценивает реальную отзывчивость голоса и не является тестом физического микрофона**. После Task 2 открой HTTPS-ссылку Pages и проверь разрешение микрофона, калибровку, слабое катание, одиночный резкий удар и отсутствие вывода звука из динамиков.
